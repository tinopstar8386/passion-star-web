Siêu Hiệu Ứng Animate UI

Bộ thư viện hiệu ứng tương tác, vật lý trọng lực hạt sao, nút nam châm (Magnetic), thẻ nghiêng 3D (Tilt), chữ phát sáng & bộ đếm số động. Dễ dàng tích hợp vào Vanilla HTML, React / Next.js hoặc Vue.

Danh Mục Hiệu Ứng & Cách Tích Hợp

Tất cả hiệu ứng dưới đây đều được xây dựng theo chuẩn của Animate-UI, có thể gọi bằng thẻ data-animate hoặc gọi hàm JavaScript.

1. Magnetic Button Physics

Nút tự động bị hút dính vào con trỏ chuột theo cơ chế lò xo (Spring physics). 

<!-- HTML / Vanilla JS -->
<div data-animate="magnetic" data-magnetic-strength="0.4">
  <button class="btn">Nút Nam Châm</button>
</div>
2. 3D Tilt Card & Glare 3D Perspective

Thẻ tự động nghiêng theo góc di chuyển chuột và tạo ánh sáng lóa gương (Glare reflection).

Di chuyển chuột quanh đây
Tính toán trục X & Y theo thời gian thực
<!-- Tự động kích hoạt khi có data-animate -->
<div class="my-card" data-animate="tilt" data-tilt-max="14">
  <!-- Nội dung thẻ -->
</div>
3. Glow / Liquid Border CSS Conic

Viền gradient xoay 360 độ liên tục tạo cảm giác phát sáng neon hiện đại.

Neon Glow Border 
<div data-animate="glow-border" style="background:#131722; border-radius:12px;">
  <span>Nội dung phát sáng viền</span>
</div>
4. Spring Number Counter Animation

Số nhảy mượt mà với gia tốc exponential ease-out như trên Animate-UI.

98450+ 
<!-- Tự động animate lên con số target -->
<span data-animate="counter" data-counter-target="98450">0</span>
<!-- Hoặc qua JS: AnimateKit.counter(element, 98450) -->
5. Typewriter Animation Text Motion

Hiệu ứng gõ chữ, tự động xóa và đổi câu tiếp theo với con trỏ nhấp nháy.

>   
<span data-animate="typewriter" 
  data-words='["Dự án 1", "Dự án 2", "Dự án 3"]'>
</span>
6. Specular Shimmer Text Gradient Mask

Vệt sáng kim loại quét ngang qua chữ tương tự phong cách Apple / Linear UI.

Hướng Dẫn Tích Hợp Vào Project Khác

Bạn có 2 lựa chọn linh hoạt tùy thuộc vào công nghệ của dự án mục tiêu:

Cách 1: Sử dụng trong React / Next.js / shadcn/ui

Nếu project khác dùng React hoặc Next.js, bạn có thể cài trực tiếp gói CLI chính thức của Animate-UI hoặc Motion: 

# Cài đặt qua CLI chính thức của Animate UI
npx @animate-ui/cli@latest add gravity-stars
npx @animate-ui/cli@latest add magnetic
npx @animate-ui/cli@latest add tilt

# Hoặc cài đặt thư viện lõi
npm i motion @animate-ui/react

Cách 2: Sử dụng trong HTML / JS Thuần / Vue / PHP / Blade

Copy thư mục animate-kit/ (gồm animate-kit.js và animate-kit.css) vào project mới của bạn: 

<!-- 1. Nhúng CSS vào thẻ <head> -->
<link rel="stylesheet" href="./animate-kit/animate-kit.css">

<!-- 2. Thêm thẻ HTML với thuộc tính data-animate tương ứng -->
<div data-animate="gravity-stars"></div>
<button data-animate="magnetic" class="btn">Button</button>
<div data-animate="tilt" class="card">Card</div>

<!-- 3. Nhúng JS trước thẻ đóng </body> (Tự động kích hoạt toàn bộ trang) -->
<script src="./animate-kit/animate-kit.js"></script>
