## 🛠️ 2. Công Nghệ & Kiến Trúc
- **Frontend:** HTML5, CSS3 hiện đại, Vanilla JavaScript (Không dùng framework nặng để đảm bảo tốc độ tải tối đa, chạy trực tiếp trên web/trình duyệt).
- **Thư viện UI/Icon:** Tailwind CSS (CDN), Bootstrap 5, FontAwesome 6, Lucide Icons, Plus Jakarta Sans font.
- **Backend & Cơ sở dữ liệu:**
  - **Firebase Firestore / Realtime Database:** Dùng cho dữ liệu đồng bộ thời gian thực (`timeline.html`, `off.html`, `idol_tracker.html`, `task_media.html`).
  - **Google Apps Script Web App:** Đồng bộ task và Google Sheets (`index.html`, `idol_tracker.html`).
- **Bảo mật & Phân quyền:**
  - Hệ thống PIN Lockout bảo vệ các quyền Admin/Quản lý (ví dụ: PIN `0908` trên trang Media/Nghỉ phép).
