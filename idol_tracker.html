Cấu Hình Lưu Trữ Firebase & Deploy Vercel

Project ID: passionstar-2014d

Phiên kết nối hiện tại (User ID): Đang khởi tạo...

1. Bật quyền ghi dữ liệu trên Firebase Console (Quan trọng khi chạy trên Vercel)

Để web trên Vercel lưu được bài đăng vào project passionstar-2014d, bạn hãy vào Firebase Console → Firestore Database → tab Rules và dán cấu hình sau rồi bấm Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

2. Bật Anonymous Auth (Tùy chọn khuyến nghị)

Vào mục Authentication → Sign-in method trên Firebase Console, bật Anonymous để định danh phiên truy cập an toàn.
