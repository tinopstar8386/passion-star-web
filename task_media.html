Đã kết nối trực tiếp tới Project ID: passionstar-2014d

Dữ liệu lịch được lưu tại collection 'media_tasks' và cấu hình nhân sự tại 'media_settings/config'.

⚠️ Lưu ý quan trọng: Mở quyền đọc/ghi (Rules) trong Firestore

Trong trang Firebase passionstar-2014d, anh bấm vào mục Firestore ở menu trái → chọn tab Rules ở trên cùng → thay nội dung bằng đoạn dưới đây rồi bấm Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

3 bước đưa file lên GitHub Pages:

  1. Bấm nút màu xanh "📥 Tải file index.html (Đưa lên GitHub)" trên thanh công cụ.
  2. Vào GitHub tạo một Repository mới (chọn Public) → bấm Add file → Upload files → tải file index.html vừa tải về lên và bấm Commit changes.
  3. Vào mục Settings → Pages trên GitHub, chọn nhánh main → bấm Save để nhận link web gửi cho bộ phận Media.
